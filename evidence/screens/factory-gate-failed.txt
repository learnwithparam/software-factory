What

Add a required toolCalls: integer field to the Run schema. The per-stage toolCalls field was already stored — each stage already tracked its own count — but the run-level total was computed client-side by summing stage records, which silently produced a wrong total when a stage record was missing.

Now the ingest service stores the authoritative run-level count, the console displays it (runs list table column + run detail header), and the three-language contract tests assert the new field.
